# OpenWave-ByteGov-
Openwave hakatonu uun hazirladigim suni intellekt inteqrasyali panel
Layihənin Pasportu
Layihənin Adı: Nərimanov Digital Twin (Rəqəmsal Əkiz)

Məqsəd: Süni intellekt və geo-analitika vasitəsilə Nərimanov Rayon İcra Hakimiyyəti ilə sakinlər arasında birbaşa, çevik və kağızsız kommunikasiya ekosistemi qurmaq.

Hədəf Auditoriyası: Rayon sakinləri və İcra Hakimiyyətinin idarəetmə heyəti.

💡 Layihə Nədir və Necə İşləyir?
"Nərimanov Digital Twin" – şəhər idarəetməsini vizuallaşdıran və avtomatlaşdıran iki tərəfli rəqəmsal platformadır:

Sakin Modulu (Mobil/Veb): Vətəndaş küçədə qarşılaşdığı problemi (məsələn: çökmüş asfalt, sönmüş işıq, tullantıların yığılması) telefonla çəkir və yerləşdiyi yerin GPS koordinatları ilə birlikdə sistemə yükləyir.

Süni İntellekt (AI) Təsnifatı: Sistemə daxil olan fotoşəkil AI tərəfindən anında analiz edilir. İnsan müdaxiləsi olmadan problemin növü (məsələn: Kommunal, Yol təmiri, Ekologiya) təyin olunur və müraciət birbaşa aidiyyatı şöbəyə yönləndirilir.

İcra Hakimiyyəti Paneli (Interactive Dashboard): İcra Hakimiyyətinin önündə rayonun interaktiv rəqəmsal xəritəsi açılır. Şikayətlər xəritə üzərində nöqtələr və istilik xəritəsi (Heat Map) şəklində vizuallaşır. Əgər bir ərazidə qırmızı rəng tündləşirsə, deməli ora təcili müdaxilə olunmalıdır.
